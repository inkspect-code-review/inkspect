# Getting help

Start with [README.md](README.md) for setup and supported commands. Open a bug
report for a reproducible problem or a feature request to discuss a proposed
change. Use the issue forms and identify the component, commit/version, OS and
redacted error output. Include a minimal synthetic reproduction where possible.

Do not attach credentials, real .env files, private repositories, database dumps
or full prompt captures. Use [SECURITY.md](SECURITY.md) for vulnerabilities and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns. Issue tracking is
community support, with no guaranteed response time.
